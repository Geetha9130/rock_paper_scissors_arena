# Rock Paper Scissors — Playzone

A responsive Rock-Paper-Scissors browser game built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Choose Rock, Paper or Scissors to play against the computer.

## Features
- Three interactive move buttons with custom emoji icons
- Random computer selection
- Correct win / loss / tie evaluation
- Animated result modal
- Player and computer scorekeeping
- Persistent scores using browser localStorage
- Sound effects with an on/off toggle
- Reset score control
- Responsive layout for desktop and mobile

## Submission proof
This ZIP is the project source. To obtain a Live Game URL, publish the folder using GitHub Pages:
1. Create a GitHub repository and upload `index.html`, `style.css`, and `script.js` to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub will provide the published URL after deployment.

Alternatively, import the project into Netlify or another static hosting provider.
